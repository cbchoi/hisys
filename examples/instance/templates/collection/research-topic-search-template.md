# Research Topic Search Template

Traceability: HISYS-TPL-RESEARCH-SEARCH-001.

## Input

```yaml
research_topic: "<topic>"
research_goal: "<goal>"
preferred_domains: []
excluded_domains:
  - paywall bypass
  - login/CAPTCHA bypass
expected_output_language: Korean
```

## Output

- Query set
- Accepted source records
- Skipped/rejected source records
- RawObservation candidates
- Audit refs
- Open questions

## Example

```yaml
research_topic: "DEVS structural change formalism for digital twin co-evolution"
research_goal: "Find publisher/journal sources for manuscript positioning."
```
